# runner-gateway guide

## Approved direction

The user selected a **routing console** on a **dark technical surface**, replacing the previous light guide. This is a developer guide, not a live monitoring dashboard.

## Visual system

- Charcoal canvas `#101518`, dark panels `#171e22`, cool near-white text `#edf2f0`.
- Lime `#b8ee8a` identifies route selection, workflow input, and primary actions. Amber marks unfinished integration.
- Self-hosted Public Sans for reading; system monospace for labels, code, and numeric data.
- Crisp borders, restrained corners, no gradients, glows, or decorative terminal controls.
- Route boundary → workflow expression → illustrative policy trace → implementation status → setup → policy commands.
- Preserve native navigation, keyboard focus, readable mobile stacking, and reduced-motion preferences.

## Product boundaries

Examples must say they are illustrative, not live usage. Bootstrap and policy evaluation are implemented separately; usage collection and automatic variable updates are not integrated. Publishing the local page does not enable or deploy GitHub Pages remotely.
